# OneSound website

The public site for **OneSound**, a live music-guessing game: a landing page
plus the Privacy Policy and Terms of Use, in English, Vietnamese and Korean.

Served by GitHub Pages from the `main` branch:

- Home: https://duckiendev.github.io/onesound/
- Privacy Policy: https://duckiendev.github.io/onesound/privacy/
- Terms of Use: https://duckiendev.github.io/onesound/terms/

Add `?lang=en`, `?lang=vi` or `?lang=ko` to open a page in that language
(the app does this). Plain HTML, CSS and JS with no build step.
